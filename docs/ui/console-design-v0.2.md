# Vega 控制台 UI 设计稿 v0.2「星光」（替代 v0.1 的视觉部分）

设计：Hark ｜ 用户要求（2026-11-21）：一眼高级、好用，像 iOS 27，不能跟 ToDesk / UU 远程撞脸。
功能结构、安全约束沿用 v0.1；本稿只改视觉、交互和下列功能点。

## 1 设计语言
- 关键词：玻璃、留白、大标题、分组列表、柔和动效。品牌意象 = 织女星 Vega（夜空里最亮的那颗）。
- 主色不用 ToDesk 蓝：Vega 靛紫 `--accent: #6C5CE7`，渐变 `--aurora: linear-gradient(135deg,#6C5CE7 0%,#8E7CFF 45%,#4FC3F7 100%)`。成功 `#30D158`，警告 `#FF9F0A`，危险 `#FF453A`（iOS 系统色）。
- 背景：浅色 `#F2F2F7`，深色 `#000`；窗口背景铺一层极淡的极光模糊（两个大圆形 radial-gradient，blur 80px，opacity 0.18，固定不动），这是识别度来源之一。
- 卡片 = iOS 分组列表（inset grouped）：白 `rgba(255,255,255,0.72)` + `backdrop-filter: blur(24px) saturate(180%)`，深色 `rgba(28,28,30,0.72)`；圆角 18px；无描边，阴影 `0 1px 0 rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`；行高 52px，行间 0.5px 分隔线从左 16px 起。
- 字体栈：`"Segoe UI Variable Display","Segoe UI Variable","PingFang SC","Microsoft YaHei UI",system-ui,sans-serif`；数字用 `font-variant-numeric: tabular-nums`。字号：大标题 30/700（-0.02em 字距）、卡片标题 13/600 大写灰色（列表分组头，放在卡片外上方）、正文 15/400、辅助 13/400 `#8E8E93`。
- 按钮：主按钮胶囊形（圆角 999px，高 40，渐变 aurora 背景，白字）；次按钮 = 浅底 `rgba(120,120,128,.12)` 胶囊；文字按钮 = accent 色无底。危险操作只用红色文字，不用红框。
- 开关 = iOS 开关（51×31，开时绿色 #30D158）；复选框全部换成开关；下拉换成 iOS 风分段控件或行尾灰字+箭头。
- 动效：页面切换 220ms 淡入+上移 8px；按钮按下 scale(.97)；状态点呼吸动画（在线时 2s 循环）。尊重 `prefers-reduced-motion`。
- 图标：线性 1.75px 描边，SF Symbols 风格，内联 SVG，不引第三方图标库。
- 深浅主题跟随系统。

## 2 窗口与导航
- 960×640 不变。标题栏透明融入背景，只保留右上三个控制点（细线图标）。
- 左栏 220px 玻璃侧栏（同卡片材质），Logo：一颗四角星 SVG + 「Vega」字标（渐变填充）。导航项为胶囊高亮（选中 = accent 12% 底 + accent 字），图标+文字。
- 底部：版本号小字 + 「检查更新」文字按钮。
- 每页顶部 iOS 大标题；内容区最大宽 680px 居中，两侧留白（不再铺满全宽，这是“高级感”的关键）。

## 6 长期密码 实现约束（安全）
- 控制台仍不常驻提权。仅在「设置/清除长期密码」时，通过 `ShellExecuteExW` verb `runas` 拉起一次提权助手；用户在 UAC 拒绝 → 提示「已取消」，不重试。
- 助手 = 安装目录内 `vega-pwhelper.ps1`（或 Rust 小可执行文件，执行层选简单的一种），以提权身份调用 `rustdesk.exe --password <pwd>`（RustDesk 官方方式）并写 verification-method；清除时设置随机 32 位高熵密码并把验证方式改回临时。
- 密码绝不进入控制台进程的命令行参数、日志、doctor 导出、state.json。从控制台到助手的传递：控制台创建一个仅当前用户+Administrators 可读的临时文件（DACL 收紧），写入后把路径传给助手，助手读后立即覆盖并删除；超时 30 s 未读也删除。`rustdesk.exe --password` 的参数在提权进程中短暂可见，这是 RustDesk 唯一官方接口，接受该风险并在 SECURITY 文档写明。
- 结果回传：助手退出码 0 成功 / 非 0 + stderr 脱敏摘要；控制台显示「长期密码已设置」或原因。
- 状态读取：从 RustDesk 配置只读取「是否设置了永久密码」与 verification-method，不读取密码内容。
- 测试：Rust 单元测试覆盖密码强度校验、verification-method 映射、临时文件 DACL 构造参数；Pester 覆盖助手脚本的参数校验与“读后删除”。
