# Vega 控制台 UI 设计稿 v0.1（M2）

设计：Hark ｜ 实现：DeepSeek 执行层（Tauri 2 + 原生 HTML/CSS/TS，无前端框架）｜ 审计：Codex

## 原则
- 零登录、零广告、零角标、零画质限制；首启即可用，“允许远程协助”默认开。
- 不自研协议：远程协助走 RustDesk，高性能串流走 Sunshine + Moonlight，控制台只是外壳和配置器。
- 安装包目标 < 15 MB（不含 RustDesk/Sunshine，本体按需用 winget 装）。
- 浅色为主，跟随系统深色；主色 #2F6BFF；圆角 10px；字体 系统默认（微软雅黑 UI / Segoe UI）。

## 窗口
- 960×640，最小 860×580，可缩放；自绘标题栏（最小化/最大化/关闭）。
- 左栏 200px：Logo「Vega」+ 三个入口：远程协助 / 我的设备 / 设置；底部显示版本号和“检查更新”。无任何推广位。

## 1 远程协助（主页）
上下两块卡片：

**本设备**
- 设备码：9 位，3-3-3 分组大字号（来自 RustDesk ID），右侧 复制 按钮。
- 临时密码：默认 ●●●●●●●●，眼睛显示，刷新按钮；刷新频率下拉：每次会话后 / 每天 / 从不。
- 一键“复制并分享”：复制「设备码 + 临时密码」一段文字。
- 开关：允许远程协助（默认开）。
- 状态行：● 已连接 ID 服务器（服务器地址可在设置改）/ ● 未连接 + 原因 + “诊断”。

**控制其他设备**
- 输入框：对方设备码（下拉显示最近 10 条）+ 连接 按钮。
- 单选：远程控制（默认）/ 文件传输。
- 连接后弹出 RustDesk 会话窗口，输入对方临时密码。

**被控时的接受弹窗**（沿用 RustDesk，自定义文案）：对方设备码与名称、勾选 键鼠 / 剪贴板 / 文件、接受 / 拒绝，60 秒超时自动拒绝。

## 2 我的设备
- 两个页签：远程协助设备 / 高性能串流。
- 远程协助设备：卡片列表（名称、设备码、在线点、上次连接时间），操作：连接 / 改名 / 删除。本地保存，不上传。
- 高性能串流：
  - 本机作为被控端：Sunshine 状态（运行中/未安装）、显卡（自动识别核显/独显，可手动选）、编码器（NVENC/AMF/QSV）、分辨率与帧率（跟随显示器，可选 1080p60 / 1440p60 / 1440p120）。按钮：安装/修复 Sunshine、打开配对（显示 PIN 输入框，转交 Sunshine 本地接口）。
  - 本机作为控制端：列出 Moonlight 已配对主机，按钮：开始串流 / 安装 Moonlight。
  - 提示条：串流需要 IPv6 直连或 Tailscale；连接不通时一键“诊断网络”。

## 3 设置
- 常规：开机自启、关闭窗口时最小化到托盘、语言（简体中文/English）。
- 安全：临时密码长度（6/8/10）、固定密码（可选，设置后无人值守）、仅允许设备列表里的设备连接、会话结束自动锁屏。
- 网络：ID/中继服务器地址与公钥（默认 Vega 自托管服务器，可改）、测试连接按钮。
- 诊断：一键运行 doctor，展示每项结果（通过/警告/失败）和修复建议，可导出脱敏日志。
- 关于：版本、MIT 许可、开源仓库链接、第三方组件许可（RustDesk AGPL 仅调用不打包）。

## 托盘
- 图标颜色表示状态（蓝=就绪，绿=被控中，灰=离线）；菜单：显示主窗口 / 复制设备码 / 断开当前会话 / 退出。
- 被控中右下角常驻小浮条：对方设备码 + 断开 按钮。

## 安全约束（继承 T1/T2）
- 密码不进命令行、日志、state.json；本地配置走 DPAPI。
- Sunshine 管理口 47990 仅本机；控制台调用本地接口时用用户本地设定的管理密码。
- 控制台不需要管理员常驻；需要提权的操作（装组件、改防火墙）单独 UAC 调起现有 PowerShell 脚本。

## 实现切分（给执行层）
- M2a：Tauri 骨架、窗口/左栏/三页静态界面、深浅主题、托盘。
- M2b：读写 RustDesk 配置（设备码、临时密码、服务器），调用 RustDesk 发起连接。
- M2c：高性能串流页对接 Sunshine/Moonlight 与现有 host/client 脚本；设置页 doctor 集成。
- 每步：Codex 审计 PASS 后合入 main；CI 增加 Tauri Windows 构建。
