# 网络与直连排查

延迟的关键是**直连**。中继服务器在国外时，绕一圈会多出 200ms 以上。

## 线路优先级

1. **局域网**：同一路由器下，Moonlight 会自动发现
2. **公网 IPv6**：国内家宽大多已下发。被控端光猫关闭 IPv6 防火墙或放行端口，Moonlight 直接添加 IPv6 地址
3. **Tailscale P2P**：自动打洞，大多数网络能直连
4. **RustDesk 中继**：以上都不行时兜底，适合应急和传文件

## 检查 Tailscale 是否直连

```powershell
tailscale ping <被控端机器名>
```

- 显示 `via 1.2.3.4:41641`：直连，正常
- 显示 `via DERP(xxx)`：走了中继，会卡。尝试：两端重启 Tailscale；路由器开启 UPnP；或改用 IPv6

## 需要放行的端口

| 用途 | TCP | UDP |
|---|---|---|
| Sunshine 串流 | 47984, 47989, 48010 | 47998-48000, 48002, 48010 |
| RustDesk 服务器（默认） | 21115-21117 | 21116 |
| RustDesk 服务器（`--websocket`） | 21118-21119 | — |

Sunshine 管理端口 **47990 不放行**：`origin_web_ui_allowed = pc` 只允许本机访问管理页，首次设密和改配置都在被控端本机做。

## 带宽

被控端**上行带宽**决定画质上限。测速看 Upload：

| 上行 | 建议 |
|---|---|
| < 20 Mbps | 1080p 60 帧 |
| 20-40 Mbps | 2K 60 帧 |
| > 40 Mbps | 2K 120 帧 |
